If, Elif & Else

Conditional statements in Python used to make decisions in programs.

What are Conditional Statements?

Conditional statements allow a program to make decisions based on whether a condition is true or false.

Python mainly uses three keywords for this:

  • if
  • elif
  • else

1. if Statement

The if statement runs a block of code when a condition is true. 

age = 18

if age >= 18:
    print("You are an adult.")

If the condition age >= 18 is true, the message will be printed.

2. elif Statement

The elif statement allows us to check another condition when the previous condition was false. 

marks = 75

if marks >= 90:
    print("Excellent")
elif marks >= 60:
    print("Good")
else:
    print("Keep practicing")

3. else Statement

The else block runs when none of the previous conditions are true. 

number = 5

if number > 10:
    print("Greater than 10")
else:
    print("10 or less")

Complete Structure 

if condition:
    # code

elif another_condition:
    # code

else:
    # code

Important Points

  • Conditions produce either True or False.
  • Python uses indentation to define blocks of code.
  • You can use multiple elif statements.
  • The else statement is optional.
