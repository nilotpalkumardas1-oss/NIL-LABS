Built-in Functions

Useful functions that are already available in Python.

What are Built-in Functions?

Python provides many functions that are already built into the language. These are called built-in functions.

We can use them directly without defining them ourselves. 

print("Hello, Nil")

1. print()

The print() function is used to display information on the screen. 

print("Hello World")

print(10)

print("Python", "Programming")

2. input()

The input() function is used to take input from the user. 

name = input("Enter your name: ")

print(name)

By default, the value returned by input() is a string.

3. type()

The type() function is used to find the data type of a value. 

name = "Nil"
age = 17

print(type(name))
print(type(age))

4. len()

The len() function is used to find the number of characters or items in an object that supports length. 

name = "Nil"

print(len(name))

Output: 

3

5. int()

The int() function can convert a value to an integer when the conversion is valid. 

age = "17"

age = int(age)

print(age)

6. float()

The float() function can convert a value to a floating-point number. 

price = "99.5"

price = float(price)

print(price)

7. str()

The str() function converts a value into a string representation. 

age = 17

text = str(age)

print(text)

8. abs()

The abs() function returns the absolute value of a number. 

number = -10

print(abs(number))

Output: 

10

9. max() and min()

max() returns the largest value, while min() returns the smallest value. 

numbers = [10, 25, 5, 40]

print(max(numbers))
print(min(numbers))

10. sum()

The sum() function adds numeric values from an iterable. 

numbers = [10, 20, 30]

print(sum(numbers))

Output: 

60

11. round()

The round() function is used to round a number. 

number = 10.567

print(round(number, 2))

Output: 

10.57

Important Points

  • Built-in functions are provided by Python.
  • They can be used directly without defining them first.
  • Different functions perform different tasks.
  • Some functions accept arguments.
  • Some functions return a value.
  • Type conversion functions such as int(), float() and str() are very useful.
