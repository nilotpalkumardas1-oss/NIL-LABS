Strings

Learn how Python stores and works with text.

What is a String?

A string is a sequence of characters used to represent text in Python.

Strings can be written using single quotes, double quotes or triple quotes. 

name = "Nil"

language = 'Python'

message = """Hello
Welcome to Python"""

Creating a String

You can create a string by assigning text to a variable. 

name = "Nil"

print(name)

String Indexing

Each character in a string has a position called an index. Python starts indexing from 0. 

text = "Python"

print(text[0])
print(text[1])
print(text[5])

Output: 

P
y
n

Negative Indexing

Python also allows negative indexes. -1 refers to the last character. 

text = "Python"

print(text[-1])
print(text[-2])

Output: 

n
o

String Slicing

Slicing allows you to extract a portion of a string. 

text = "Python"

print(text[0:3])
print(text[2:6])

Output: 

Pyt
thon

Useful String Methods

Python provides many useful methods for working with strings. 

text = "python programming"

print(text.upper())
print(text.lower())
print(text.title())
print(text.capitalize())

Finding Text

The find() method can be used to find the position of a substring. 

text = "Python Programming"

print(text.find("Python"))

Replacing Text

The replace() method replaces part of a string with another value. 

text = "I like Java"

text = text.replace("Java", "Python")

print(text)

Important Points

  • Strings are sequences of characters.
  • Python uses zero-based indexing.
  • Strings support positive and negative indexing.
  • Strings can be sliced.
  • Python provides many built-in string methods.
